# Three Colors of Madness — Chapter One 2.5D Prototype

This is a blockout-quality Godot 4 prototype of three connected Chapter One vertical slices:

1. **Rose Garden** — investigation, selective color, clue collection, and the opening frame transition.
2. **Corwin's Room** — witness account, evidence-board linking, case-file persistence, and visual instability.
3. **The Descent** — perception-revealed detail, forced flask loss, environmental stealth, and a fail/reload loop.

## Controls

- `WASD` — move
- `F` or left mouse button — interact
- `Tab` — open/close the case UI
- `1`, `2`, `3` — development shortcuts between slices

The prototype intentionally contains no sound or music. Revival and danger cues are represented visually for now. All geometry and characters are placeholders generated from primitive meshes at runtime.

## Run

Open `project.godot` in Godot 4.7 or run:

```powershell
& 'C:\Portables\Godot4\Godot_v4.7.2-stable_mono_win64_console.exe' --path '<project folder>'
```
